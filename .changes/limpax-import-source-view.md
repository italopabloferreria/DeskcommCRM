titulo: Consulta de dados originais nos lotes de importação

O detalhe de um lote permite expandir os valores originais, com aba e linha física quando disponíveis. A lista identifica a aba de origem. Fórmulas são exibidas como texto, sem execução. Não altera cadastros nem mescla contatos.
